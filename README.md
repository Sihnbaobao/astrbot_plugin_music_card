# 音乐链接转网易云卡片

将 QQ音乐 / 酷狗 / 网易云 链接自动转为网易云原生卡片（`type:"163"`）。

## 功能

- 网易云、QQ音乐、酷狗链接自动转卡片
- LLM 工具 `search_songs` + `send_song_card`：bot 聊天中自主搜歌发卡片
- LLM 工具 `listen_song` + `comment_song`：读歌词/热评理解一首歌，再去评论区留言
- 插件页「听歌」：网易云扫码登录、手动触发听歌、听歌与评论记录可视化

## 环境

AstrBot >= 4.26 · aiocqhttp + NapCatQQ · Python >= 3.10 · httpx

## 插件页：听歌

WebUI 里 **插件 → 听歌** 打开。

- **登录**：手动 Cookie（服务器 IP 被网易云风控，扫码和密码登录都不可用）。登录后才能发评论
- **听一首**：留空 → 它按人格喜好自己挑一首；也可以填歌名/歌手指定。听完读歌词/翻译/热评，写一句听后感；勾选「顺便评论」会发到评论区
- **最近在听 / 我的评论**：时间、歌名、听后感、评论内容与成功状态
- **听歌人格**：下拉选择人格，另可填一段「人格补充」——发评论前可以在这里收紧口径，比如“不提私密设定、语气克制”
- **收藏与歌单**：开启 `AUTO_SAVE` 后，听完评分达到阈值会自动红心并加入「前缀·分类」歌单；聊天里也能调 `like_song` / `save_to_playlist`
- **收到的回复**：定时检查自己评论下的新回复；可勾选「有人回复时自动回复」，用同一套人格回一句

> 评论会挂在扫码用的网易云账号下，默认每天最多 3 条，可在配置页调整。
