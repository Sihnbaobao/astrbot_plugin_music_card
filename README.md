# 音乐链接转网易云卡片

将 QQ音乐 / 酷狗 / 网易云 链接自动转为网易云原生卡片（`type:"163"`）。

## 功能

- 网易云、QQ音乐、酷狗链接自动转卡片
- LLM 工具 `search_songs` + `send_song_card`：bot 聊天中自主搜歌发卡片

## 安装

```
https://github.com/Sihnbaobao/astrbot_plugin_music_card
```

## 环境

AstrBot >= 4.26 · aiocqhttp + NapCatQQ · Python >= 3.10 · httpx
